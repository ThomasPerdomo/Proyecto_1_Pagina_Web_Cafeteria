# Proyecto Pagina Web Granos del Sol 

He diseñado una página web inspirada en una cafetería colombiana ficticia llamada "Granos del sol", hecha con Flask, HTML y CSS.
En la pagina podras encontrar informacion sobre la empresa y el menu que ofrece la cafeteria. He decidido crear este sitio web
para poder mejorar mis habilidades con el Frontend, HTML y CSS. Espero que si les interesa puedan revisarlo y darme algunas 
recomendaciones y consejos a seguir.

(Este proyecto es realizado con cero IA debido a que apenas estoy aprendiendo al desarrollo web y quiero aprender lo mejor posible) 

## Cómo ejecutarla

1. Instalar Flask: `pip install flask`
2. Ejecutar: `python main.py`
3. Abrir `http://127.0.0.1:5000`
